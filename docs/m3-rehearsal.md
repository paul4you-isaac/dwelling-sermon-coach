1. **성서공회 사이트가 없는 역본을 요청받으면 개역개정을 조용히 돌려줌.** NA28·BHS를 요청했는데 개역개정이 왔습니다. 응답의 성경 ID와 글자 종류를 대조하도록 고치고, 원어는 die-bibel.de에서 받습니다.
2. 소제목을 사이에 두고 나뉜 절(요 16:4)에서 띄어쓰기가 빠지고, 구 화면 파서가 뒤 반절을 놓쳐 거짓 `differ`가 났습니다. 둘 다 고쳤습니다.
3. 시편은 소제목 대신 편이 단락이므로 앞·뒤 편 전체를 페리코페로 씁니다.
4. 비공개 점검에서 7A에 인용한 성경 구절이 다른 파일과 겹쳐 거짓 경보가 났습니다. 7A 이전 단계(01~06)에 이미 있던 문장은 7A 문장으로 보지 않게 했습니다.

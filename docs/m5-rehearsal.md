- 일시: 2026-11-20
- 대상: S_20261108(고린도후서 4:1-18) 사본을 임시 볼트에 두고 진행했습니다. 실제 볼트는 건드리지 않았습니다.
- CLI: Claude Code 2.1.325, 모델 sonnet, 구독 로그인(서버가 `ANTHROPIC_API_KEY`를 자식 환경에서 뺌)
- 구성: `app/gate.py`(단계별 권한·호출 인자) · `app/jobs.py`(버튼 일) · `app/server.py` 경로 4개

## 호출 형태
```
claude -p --setting-sources project --settings <임시 gate-stage{N}.json>
  --strict-mcp-config --mcp-config '{"mcpServers": {}}'
  --tools Read,Glob,Grep --allowedTools "Read(./**)" "Glob(./**)" "Grep(./**)"
  --permission-mode dontAsk --max-turns 6 --max-budget-usd 0.5 --model=sonnet --safe-mode
  --system-prompt-snapshot off --append-system-prompt-file <임시 지침> --output-format json [--resume=<세션 UUID>]
```
- 셸 없이 인자 목록으로 실행하고, 질문은 stdin으로 넘깁니다. 실행 위치는 주간 폴더입니다.
- `gate-stage{N}.json`: `disableAllHooks`, deny = Write·Edit·NotebookEdit·Bash·WebFetch·WebSearch·Agent·Task + Read·Glob·Grep 각각에 대해 `07A_*`·`06A_*`·`*묵상종합*`·`00_수집/ask_log.jsonl`(모든 단계), `00_수집/주석/**`(0~3·7A 단계), 비공개 표시가 있는 파일(부를 때마다 찾음, NFC·NFD 둘 다), `stage3_apply_private`이면 `03_원어관찰*`.
- `--plugin-dir`는 넣지 않았습니다. 버튼은 하위 에이전트를 부르지 않고, 스킬이 자동으로 끼어들지 않게 하려는 것입니다.

## 시험 (`python3 -m unittest discover -s app/tests`, 가짜 claude 실행 파일)
- 인자·stdin·실행 위치·API 키 제거, 단계별 deny 규칙(0·1·2·3·4·7A·7B·9), 세션 이어 가기와 단계가 바뀌면 새 세션, 시간 초과·오류·깨진 응답, 동시 3개 중 1개만, 잘못된 입력, 구판 주간 거부.
- 다시 수집: 확인 필수, 원어관찰 기록이 있는데 이전 수집본이 깨졌으면 거절(파일 그대로).
- 진행 상황 점검: 비공개 오류 개수는 알리되 7A 문장은 응답에 없음.
- 일부러 망가뜨려 보기: 주석 게이트·7A 거부·API 키 제거·도구 제한을 하나씩 끄면 시험이 실패했습니다.

## 리허설에서 찾아 고친 것
1. 첫 시험에서 모델이 지침만 보고 스스로 거절해, 권한 층이 막는지는 드러나지 않았습니다. 지침 없이 읽기를 시키는 시험을 따로 두어 권한 거부를 확인했습니다.
2. `ask_log.jsonl`을 버튼 경로가 읽을 수 있었습니다. 7A 단계에서 적은 질문이 뒤 단계 답으로 새지 않게 막았습니다.
3. 「본문 다시 수집」 결과가 화면을 다시 그리면서 사라졌습니다. 마지막 결과를 남기게 고쳤습니다.

# 7단계 상세 진행 가이드

## Stage 1 — 본문 만남 (주일 오후)

**목표**: 분석 없이 본문을 처음 만납니다.

### 진행 방식

1. 설교자가 제시한 본문을 확인합니다.
2. 본문 검증 라인업에 따라 번역본을 fetch합니다.
3. 5개 번역 + 원어 탭 HTML 아티팩트를 생성합니다. (TTS 포함)
4. 설교자에게 본문을 천천히 읽도록 안내합니다.
5. 다음 질문 하나만 던집니다:

```
본문을 읽으며 어떤 단어나 장면이 마음에 걸렸습니까?
분석하지 말고, 그냥 떠오르는 것을 말씀해 주십시오.
```

### 산출물

파일명: `01_본문만남_{날짜}_{본문}.md`

- 사용자가 말한 첫 반응을 그대로 기록합니다.
- 클로드가 해석하거나 요약하지 않습니다.
- 다음 Stage로 넘어가지 않습니다. 설교자가 먼저 요청해야 합니다.

---

## Stage 2 — 본문과 동행 (월·화·수, 매일 짧게)

**목표**: 매일 짧게 본문과 만납니다. 분석이 아닌 관찰입니다.

### 진행 방식

각 요일마다 별도 항목을 기록합니다.
클로드는 받아 적는 역할만 합니다.

매일 세션 시작 시 같은 질문을 합니다:

```
오늘 본문을 읽으며 새롭게 보인 것이 있습니까?
또는 어제와 다르게 느껴진 것이 있습니까?
```

### 산출물 구조

각 항목: 요약(1~3문장) + `<details>` 블록에 원본 전체 보존

```markdown
### 월요일
요약: 설교자가 말한 핵심 한 문장

<details>
<summary>원본 기록</summary>
설교자가 말한 내용 전체
</details>
```

파일명: `02_동행일지_{날짜}_{본문}.md`

---

## Stage 3 — 1차 청중 만나기 (수요일)

**목표**: 본문이 처음 들려진 청중을 상상합니다.

### 진행 방식

클로드는 본문의 1차 청중을 간략히 소개합니다.
(해석이 아닌 역사적·문화적 배경 소개)

이후 설교자에게 묻습니다:

```
이 본문이 처음 들려진 사람들은 어떤 상황이었을까요?
그들이 이 말씀을 들었을 때 어떤 감정이었을 것 같습니까?
```

페르소나별 음성 차등 TTS HTML 아티팩트를 함께 생성합니다.

### 산출물

파일명: `03_청중만남_{날짜}_{본문}.md`

- 설교자의 상상을 받아 적습니다.
- 클로드가 '정답'을 제시하지 않습니다.

---

## Stage 4 — 맥락 살피기 (수·목)

**목표**: 본문이 놓인 페리코프(pericope)를 확인합니다.

### 진행 방식

페리코프 3단 시각적 위계 HTML 아티팩트를 생성합니다:
- 상위 맥락 (책 전체 흐름)
- 중간 맥락 (인근 단락)
- 직접 맥락 (본문 바로 앞뒤)

클로드는 맥락 정보를 제공합니다.
이후 설교자에게 묻습니다:

```
이 맥락을 보고 나니, 본문이 다르게 읽히는 부분이 있습니까?
```

### 산출물

파일명: `04_맥락살피기_{날짜}_{본문}.md`

---

## Stage 5 — 묵직한 한 단어 (목요일)

**목표**: 본문 전체를 하나의 단어로 압축합니다.

### 진행 방식

설교자에게 묻습니다:

```
지금까지 본문과 동행하면서, 가장 무겁게 남은 단어 하나가 있다면 무엇입니까?
단어 하나만 말씀해 주십시오.
```

설교자가 단어를 말하면:
1. 그 단어를 받아 적습니다.
2. 원어(히브리어 또는 헬라어)를 함께 확인합니다.
3. 설교자가 원하면 `biblical-word-study` 스킬로 연계합니다.

### 산출물

파일명: `05_묵직한단어_{날짜}_{본문}.md`

---

## Stage 6 — 오늘 적용 (금요일)

**목표**: 설교자 자신에게 먼저 적용합니다. 그 다음 회중에게.

### 국면 A — 자기 적용 (분석 중단)

이 국면에서 클로드는 **분석·요약·신학적 해설을 일시 중단**합니다.

설교자에게 묻습니다:

```
이 말씀이 지금 목사님 자신에게는 어떻게 말씀하고 있습니까?
회중을 향한 설교 전에, 먼저 목사님 자신을 향한 말씀으로 들으십시오.
```

설교자가 나누는 내용을 그대로 받아 적습니다.
평가하거나 요약하거나 신학화하지 않습니다.

산출물: `06A_자기적용_{날짜}_{본문}.md` (YAML에 `private: true` 추가)

### 국면 B — 회중 적용

국면 A 이후, 회중을 향한 적용으로 넘어갑니다.

설교자에게 묻습니다:

```
이 말씀이 지금 회중에게는 어떻게 말씀하고 있습니까?
FCF(타락 조건 초점)는 무엇입니까?
그리스도 안에서의 응답은 무엇입니까?
```

심화가 필요하면 `chapell-christ-centered` 스킬로 연계합니다.

산출물: `06B_회중적용_{날짜}_{본문}.md`

## Stage 7 — 원고 4문 점검 (토요일)

**목표**: 완성된 설교 원고를 4가지 질문으로 점검합니다.

### 4문 점검 항목

1. **본문이 말하는가?** — 설교가 설교자의 생각이 아니라 본문에서 흘러나오는가?
2. **FCF가 살아 있는가?** — 회중의 타락 조건이 선명하게 드러나는가?
3. **그리스도가 중심인가?** — 도덕주의가 아니라 복음이 설교의 중심인가?
4. **적용이 구체적인가?** — 오늘 이 회중의 삶에 닿는 적용인가?

클로드는 설교자의 원고를 받아 위 4문으로 점검합니다.
약점을 지적하되, 설교자가 직접 수정합니다.
원고 편집이 필요하면 `sermon-editor` 스킬로 연계합니다.

### 산출물

파일명: `07_원고점검_{날짜}_{본문}.md`

---

## 스킬 사용 권장 조건

### 적합한 경우
- 다음 주일 설교를 한 주 단위로 준비할 때
- 분석 중심이 아닌 묵상 중심의 설교 준비를 원할 때
- 본문에 머무르는 시간을 가질 수 있는 사역 일정일 때

### 적합하지 않은 경우
- 빠른 설교 준비가 필요한 긴급 상황 (장례 설교 등)
  → `baxter-sermon-coach` 또는 `sermon-coach` 사용
- 묵상 없이 즉시 원고를 다듬어야 할 때
  → `sermon-editor` 사용

# 원어 구문 분석 규격 (Stage 3 원어관찰)

Stage 3 원어관찰의 본문 화면은 **헬라어 구문성경 「구문 묵상 뷰어」**와 같은 틀을 씁니다.
기준 문서: 설교자의 `헬라어 구문성경/CLAUDE.md` §2~§5 · `템플릿/구문묵상뷰어_템플릿.html`.
신약·구약 모두 같은 틀이고, 구약은 문법 분해만 히브리어 체계로 적습니다(§4).

---

## 1. 절 하나의 모양

```
┌──────────────────────────────────────────────────────────────┐
│ [위] 절 번호 + 원어 전체 절 (주동사 강조)                         │
├───────────────────────────┬──────────────────┬───────────────┤
│ ① 구문별 5중 인터리니어      │ ② 주동사 구문 해설  │ ③ 묵상 노트      │
│   라벨 (Deppe)              │   · 동사 계단      │   (설교자,       │
│   ❶ 원어 구문               │   · 해설 2~4문장   │    절마다 하나)   │
│   ❷ 문법 분해               │   · [이문: …]      │                │
│   ❸ 자체 직역 (청크 `/`)     │                  │                │
│   ❹ 새한글                  │                  │                │
│   ❺ ESV                    │                  │                │
└───────────────────────────┴──────────────────┴───────────────┘
```

- ①·② 는 감독(클로드)이 만들어 `00_수집/syntax.json`에 넣습니다. 화면에서는 【AI】로 표시합니다.
  단, ❶ 원어·❹ 새한글·❺ ESV는 **수집본(passage.json)의 글자 그대로**입니다.
- ③ 묵상 노트는 **설교자만** 씁니다. 감독은 비워 둡니다. 저장은 `03_원어관찰.json`(절마다 하나).
- ② 주동사 해설은 Stage 3 원어관찰에서 **처음부터 보입니다**(설교자 결정, 2026-11-20). 적용·설교 포인트·예화는 쓰지 않습니다.

## 2. 본문 조달 — 만들어 내지 않습니다

1. ❶ 원어는 수집본의 NA28(신약)·BHS(구약) 절 본문을 **낱말 그대로·순서 그대로** 나눕니다.
   - 스크립트가 낱말 하나씩 수집본과 맞춥니다(악센트·기식·모음까지. 문장부호와 히브리어 강세 부호만 빼고 비교). 낱말 하나를 둘로 쪼개거나 둘을 하나로 붙이면 안 됩니다. 히브리어 마켑(־)으로 이어진 낱말은 마켑 뒤에서 나눌 수 있습니다.
   - 맞으면 **수집본 글자로 바꿔 넣습니다.** 화면과 파일에는 늘 수집본 글자만 나갑니다.
   - 생략된 동사 자리는 `{"g": "⟨ … ⟩", "gap": true, "p": "3절에서"}`처럼 ⟨ ⟩ 꼴(40자 이하)로만 둡니다. 화면에서 【AI】로 보입니다.
   - `main_verbs`와 `chain`의 낱말도 그 절 수집본 낱말이어야 합니다.
2. ❹ 새한글·❺ ESV는 수집본 해당 역본에서 **잘라 붙입니다.** 어휘·어미·띄어쓰기를 바꾸지 않고, 낱말 가운데서 자르지 않습니다.
   새한글은 긴 문장을 끊어 번역하므로 다른 절의 글이 올 수 있습니다(수집본 본문 범위 안). ESV는 그 절과 앞뒤 한 절 안에서만 가져옵니다.
   맞는 부분이 없으면 빈칸으로 둡니다(지어내지 않음).
3. 기억이나 추정으로 성경 글자를 채우지 않습니다. 한 어절도 예외가 없습니다.
4. 중요한 이문은 그 절 `variant`에 `[이문: …]` 한 줄로 남깁니다.

## 3. 신약 — 문법 분해 (김상훈 SGGNT)

유의미한 낱말(동사·분사·부정사·주요 명사구)에 붙입니다. 관사·접속사도 붙여도 됩니다.

| 품사 | 표기 | 예 |
|---|---|---|
| 정동사 | `동{법}.{시제}{태}.{인칭}{수}` | `동직.현완능.1복` · `동명.현능.2복` |
| 분사 | `분.{시제}{태}.{격}{성}{수}` | `분.현능.주남단` |
| 부정사 | `부정사.{시제}{태}` | `부정사.과능` |
| 명사·형용사·대명사·관사 | `{품사}.{격}.{성}{수}` | `명.소.여단` · `대인칭.주.1복` · `관.목.남단` |
| 전치사·접속사·부사 | `전` · `접` · `부` (필요 시 `전(+소)`) | |

- 법: 직 · 가 · 명 · 희 / 시제: 현 · 미완 · 과 · 현완 · 과완 · 미 / 태: 능 · 중 · 수 · 중수
- 격: 주 · 소 · 여 · 목 · 호 / 성: 남 · 여 · 중 / 수: 단 · 복
- 불확실하면 끝에 `?`를 붙이고 해설에 이유를 한 줄 적습니다. 확실한 척하지 않습니다.

## 4. 구약 — 문법 분해 (히브리어)

| 품사 | 표기 | 예 |
|---|---|---|
| 동사 | `동{어간}.{형}.{인칭}{성}{수}` | `동칼.완.3남단` · `동피.미완.2남복` · `동칼.와미완.3남단`(와우연속) |
| 명령·지시·청유 | `동{어간}.명.2남단` · `동{어간}.지시.3남단` · `동{어간}.청유.1단` | |
| 분사 | `분{어간}.{능/수}.{성}{수}` | `분칼.능.남단` |
| 부정사 | `부정사{어간}.연계` · `부정사{어간}.절대` | |
| 명사·형용사 | `{품사}.{성}{수}.{절대/연계}` | `명.남단.연계` |
| 접두·접미 | 앞에 `접(와우)+` · `전(בְּ)+` · `관+`, 뒤에 `+접미3남단` | `전(לְ)+명.남단.절대+접미1공단` |

- 어간: 칼 · 니 · 피 · 푸 · 히 · 호 · 히트 / 형: 완 · 미완 · 와미완 · 와완
- 구문 행은 오른쪽→왼쪽으로 놓습니다. 문장 단위는 아트나흐·소프 파숙을 참고하되, 라벨은 §5를 따릅니다.

## 5. 절 유형 라벨 (Deppe, Lexham Clausal Outline)

| 계열 `family` | 라벨 `label` 예 | 색 |
|---|---|---|
| `main` 주동사 | `main verb` `main verbs` `imper` `verb fut` `(verb)` | `#7B5E2A` |
| `ptc` 분사 | `att ptc` `ptc peri` `adv ptc temp` `adv ptc means` `supple percep` | `#B5174A` |
| `inf` 부정사 | `comple inf` `art inf pur` | `#222222` |
| `pur` 목적 | `pur` (ἵνα/ὅπως · לְמַעַן) | `#1255A0` |
| `rel` 관계 | `rel cl` `indef rel cl` | `#C45000` |
| `causal` 원인·인용 | `causal` `recit ὅτι` `indir state` | `#4A7A20` |
| `quest` 의문 | `quest` | `#5A0E90` |
| `cond` 조건 | `log cond` | `#6A6A6A` |
| `plain` 등위·부차 | `(verb) 등위절` | `#6A6A6A` |
| `prep` 전치사구 | `prep phr` | `#0c8599` |
| `par` 삽입 | `parenth` | `#5A0E90` |
| `etc` 기타 | `appos` `compar cl` `address voc` `pred nom` `loc cl` `pendent nom` | `#666666` |

- 들여쓰기 `indent`: 주동사 0 → 직속 종속 1 → 2차 종속 2 (최대 3). 병렬은 같은 단계.

## 6. ❸ 자체 직역 · ② 해설

- 직역은 원어 어순·청크를 지킵니다. 한국어 자연스러움보다 **구조가 보이는 것**이 먼저입니다. 청크는 ` / `로 끊습니다.
- 동사 계단 `chain`: 절의 동사를 순서대로, 시제·태가 만드는 뜻을 짧게.
- 해설 `commentary` 2~4문장: ① 주동사가 무엇이고 왜 주동사인가 ② 시상·태·법의 뜻 ③ 종속 요소가 어디에 걸리는가 ④ 그래서 저자가 무엇을 강조하는가.
  **적용·설교 포인트·예화는 쓰지 않습니다.** 주석(00_수집/주석/)을 인용하지 않습니다(Stage 3 원어관찰은 주석 게이트 안).

## 7. `00_수집/syntax.json` 모양

```json
{
 "dsc_version": "1.0.0", "reference": "고린도후서 4:7-9", "testament": "NT", "original": "NA28",
 "made_by": "감독(claude)", "made_at": "2026-11-20T15:00:00+09:00",
 "verses": [
  {"ref": "4:7", "title": "질그릇에 담긴 보배",
   "main_verbs": ["Ἔχομεν"],
   "clauses": [
    {"id": "4.7a", "label": "main verb", "family": "main", "indent": 0,
     "words": [{"g": "Ἔχομεν", "p": "동직.현능.1복"}, {"g": "δὲ", "p": "접"}],
     "literal": "우리가 가지고 있다 / 그런데", "nk": "…", "esv": "…"}],
   "chain": [{"verb": "Ἔχομεν", "note": "현재 — 지금 가지고 있음"}],
   "commentary": ["…", "…"],
   "variant": ""}
 ]
}
```
- 절 범위는 수집본 범위 안이면 됩니다(일부 절만 먼저 만들어도 됨). 없는 절은 작업창이 수집본만으로 보여 줍니다.
- 작업창과 생성본은 읽을 때마다 `syntax.json`을 지금 수집본과 다시 대조합니다. 본문을 다시 수집해 글자가 바뀐 절은 보이지 않고 「다시 만들어 달라」는 안내가 뜹니다.
- `id`는 `장.절` + 알파벳입니다. 묵상 노트는 **절**에 붙으므로, 구문 분석을 고쳐 다시 넣어도 노트는 그대로입니다.

## 8. 만드는 순서 (감독)

1. 수집본 `00_수집/passage.json`을 읽습니다(원어·새한글·ESV).
2. §2~§6대로 `00_수집/구문분석_초안.json`을 씁니다. 한 번에 4~8절, 20절이 넘으면 나누어 여러 번 넣습니다.
3. 수집 에이전트에 `task: syntax`를 맡깁니다. 스크립트가 검사(원어 낱말 일치·주동사·새한글/ESV 글자 대조·라벨·분해 표기)한 뒤
   `00_수집/syntax.json`에 합쳐 넣고 초안을 지웁니다. 실패하면 문제 목록을 돌려주고 아무것도 바꾸지 않습니다.
4. 문제 목록이 오면 초안을 고쳐 다시 맡깁니다. 설교자에게는 「구문 분석을 작업창에 올렸습니다」 한 줄만 전합니다.

## 1. 산출물 저장 경로 (v2.0.3)

본 스킬의 모든 산출물은 **설교자 Obsidian 볼트** 절대 경로에 저장합니다.

```
~~sermon-vault/00-inbox/prep_sermon/
└── S_{다음주일_YYYYMMDD}/                # 주차별 하위 폴더
    ├── 01_본문만남_{YYYY-MM-DD}_{본문}.md
    ├── 02_동행일지_{기간}_{본문}.md
    ├── 03_1차청중_{YYYY-MM-DD}_{본문}.md
    ├── 04_맥락관찰_{YYYY-MM-DD}_{본문}.md
    ├── 05_묵직한단어_{YYYY-MM-DD}_{본문}.md
    ├── 06A_자기적용_{YYYY-MM-DD}_{본문}.md   (private: true)
    ├── 06B_회중적용_{YYYY-MM-DD}_{본문}.md
    ├── 07_원고점검_{YYYY-MM-DD}_{본문}.md
    ├── 설교_{YYYYMMDD}_{본문}_묵상종합.md   ← Stage 7 자동 생성
    ├── Stage1_{본문}_본문만남.html
    ├── Stage3_{본문}_1차청중_페르소나.html
    └── Stage4_{본문}_페리코프3단.html
```

### 입력 자료 위치 (자유)

- `~~sermon-vault/00-inbox/articles/` · `books/` · `youtube/`
- `~~sermon-vault/01-wiki/` (분류된 참고 자료)
- `~~sermon-vault/02-sermons/` (과거 설교)

### 폴더 경로 변경 이력

| 버전 | 산출물 루트 |
|---|---|
| v0.1.0~v2.0.1 | (프로젝트 폴더)/`output/` |
| v2.0.2 | (프로젝트 폴더)/`prep_sermon/` |
| **v2.0.3 (현재)** | **`~~sermon-vault/00-inbox/prep_sermon/`** |

### 하위 규칙 불변성

루트 경로가 어디로 옮겨가도 **하위 폴더·파일명 규칙은 모두 그대로**:

- 서브폴더: `S_{다음주일_YYYYMMDD}/`
- 모든 Stage 마크다운·HTML 파일명 규칙
- 묵상종합 파일명 규칙
- YAML frontmatter 형식

**T_** = This week (이번 주일) · **S_** = Sermon (다음 주일 설교)

### 설교일 자동 계산

설교일 미입력 시 오늘로부터 **다음 주일(일요일)**을 자동 계산합니다.
- 오늘이 일요일이면 다음 주 일요일
- 그 외 요일은 가장 가까운 다음 일요일

## 4. 묵상종합 템플릿 (v2.0 신규, v2.0.7 원문 보존 규칙 통합)

### 원문 보존 원칙 (필수 — v2.0.7)

묵상종합 파일은 한 주 묵상의 **원본 기록의 결산**입니다. 각 Stage에서 사용자가 입력한
묵상 원문을 **변형·요약·재작성 없이 원본 그대로** 포함해야 합니다.

**보존 대상**:
- Stage 1 — 첫 단어 + 첫 반응 메모
- Stage 2 월·화·수 동행일지 원문 (details 블록 그대로)
- Stage 3 — 사용자가 떠올린 페르소나 원문
- Stage 5 — 묵직한 단어 발견 시 사용자 신학적 통찰 원문
- Stage 6A — 자기 적용 원문 (private 표기와 함께)
- Stage 6B — 회중 적용 원문

**보존 형식**:
1. 짧은 원문 — 본문 안에 그대로 (인용부 「」)
2. 단락 원문 — 단락 단위로 그대로 포함
3. 클로드 요약 추가 시 — 원문은 `<details>` 블록에 항상 보존

**금지 사항**:
- 사용자 원문의 핵심 표현을 다른 어휘로 바꾸지 않음
- 사용자의 호흡·강조·문장 길이 그대로
- 명백한 받아쓰기·구술 입력 오탈자만 최소 교정
- 「풀어 주는」 신학적 해설로 가공 금지

「누적 곡선 표」·「구속사 곡선」 같은 클로드 추가 항목은 묵상종합 후반부에만 배치합니다.

## 7. Obsidian 연동 권장 설정

이 스킬의 산출물은 Obsidian YAML 형식과 호환됩니다.
Obsidian 볼트의 `주간묵상 설교준비/` 폴더가 이 스킬의 작업 폴더입니다.
input/output 구조 그대로 Obsidian에서 인덱스 가능합니다.

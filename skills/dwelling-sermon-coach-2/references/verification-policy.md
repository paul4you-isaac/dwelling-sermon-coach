# 본문 검증 정책 v2.0

본 문서는 본 스킬이 모든 본문 표시에 적용하는 **검증 정책**을 명문화합니다.

---

## 1. 검증 출처 일원화

| 본문 종류 | 1차 출처 | 정책 |
|---|---|---|
| 한국어 4개 번역 (개역개정·새번역·새한글·공동번역) | bible.bskorea.or.kr | 필수 |
| 영어 ESV | esv.org / Crossway 공식 | 필수 |
| 구약 원문 BHS | academic-bible.com / Deutsche Bibelgesellschaft | 권장 |
| 신약 원문 NA28 | academic-bible.com / Nestle-Aland | 권장 |
| 가톨릭 성경 | cbck.or.kr (한국천주교주교회의) | 옵션 |

bskorea URL 패턴: `/bible/{번역코드}/{책코드}.{장}`
- NKRV = 개역개정
- RNKSV = 새번역
- NHKR = 새한글
- CTKKR = 공동번역 개정판

---

## 2. 3단 Fallback

```
1차: bskorea/esv/academic-bible 자동 fetch
  ↓ 실패 시
2차: web_search로 다중 출처 교차 검증
  ↓ 그래도 모호하면
3차: 사용자에게 권위 본문 요청 — 사용자 제공 본문을 정답으로 채택
```

---

## 3. 검증 에이전트 (필수)

본문 검증은 **선택이 아닌 필수**입니다.
클로드의 사전 지식만으로 4개 번역 본문을 출력하면 신뢰할 수 없습니다.

### 시범에서 발견된 실제 오류

| 번역 | 절 | 오류 |
|---|---|---|
| 새번역 | 3 | 「복을 비는」 → 「축복하는」, 「복을 내리고」 → 「복을 베풀고」 |
| 새번역 | 9 | 「네겝에 이르렀다」 누락 (결말 흐림) |
| 개역개정 | 7 | 「여호와를 위하여」 → 「여호와께」, 「그 곳에」 → 「그 곳에서」 |
| 공동번역 | 6 | 「세겜에 있는」 → 「세겜 성소」 (신학적으로 결정적) |

이런 오류는 단순 문자 차이가 아니라 **본문의 신학적 의미를 흐립니다**.
검증 에이전트는 단순 문자 비교가 아닌 **신학적으로 결정적인 표현이 살아 있는지** 점검합니다.

---

## 4. 메타데이터 표기

검증된 본문은 산출물에 다음 메타데이터를 함께 표시합니다.

```
검증 출처: bible.bskorea.or.kr (NKRV)
검증 일자: YYYY-MM-DD
검증 방법: 자동 fetch / 교차 검증 / 사용자 제공
```

---

## 5. 표기 통일

| 공식 명칭 | 본 스킬 약칭 |
|---|---|
| 성경전서 개역개정판 | 개역개정 |
| 성경전서 새번역 | 새번역 |

| English Standard Version | ESV |
| Biblia Hebraica Stuttgartensia | BHS |
| Nestle-Aland 28th Edition | NA28 |

## 6. 원어 자동 선택

| 본문 종류 | 원어 |
|---|---|
| 구약 39권 | BHS (히브리어 / 일부 아람어) |
| 신약 27권 | NA28 (그리스어) |

본문을 받으면 자동으로 구약/신약을 판별하여 해당 원어 탭을 표시합니다.
원어 TTS는 비활성화합니다 (음성 안정성 부족).

---

## 7. 저작권 고지 (필수)

새번역 본문은 대한성서공회 저작입니다.
페리코프 단위 인용은 묵상·설교 준비를 위한 학습적 사용에 해당하지만,
산출물에 다음 한 줄을 의무화합니다.

```
※ 외부 배포·출판 시 대한성서공회 허락이 필요합니다.
```

Obsidian 노트로 누적되더라도 **외부 유포 시 문제 소지를 차단**합니다.

---

## 8. 사용자 권위 본문의 우선

자동 검증이 실패하거나, 사용자가 직접 권위 본문을 제공하면 그것을 **최우선 정답**으로
채택합니다. 이 정책은 시범 운영에서 매우 효과적임이 검증되었습니다.

사용자가 bskorea·esv·academic-bible 출처에서 직접 가져온 본문은
검증 출처 자체보다 신뢰도가 높습니다 (선택적 가공·오류 가능성 없음).
